## 🚀 How to View & Share

### 1. View Locally (Instant)
- Double-click [`launch-menu.bat`](launch-menu.bat) or open [`index.html`](index.html) in Chrome or Edge.
- Or double-click [`start-server.bat`](start-server.bat) to run a local web server at `http://localhost:8080`.

### 2. Share a Single Website
- Each folder is 100% self-contained. You can zip any single folder (e.g. `02-design-studio/`) and email it, or drag-and-drop it into Netlify Drop / Cloudflare Pages.

### 3. Deploy to GitHub Pages / Web
- Push this repo to GitHub and enable **GitHub Pages** (Settings > Pages > Deploy from branch `main` / root).
- All sites will immediately be accessible at `https://<organization>.github.io/<repo>/`!
